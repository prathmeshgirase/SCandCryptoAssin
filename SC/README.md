## Soft Computing (Practical V) – Python Solutions

Run with Python 3:

```bash
python Q1_fuzzy_operations.py
python Q2_fuzzy_composition.py
python Q3_demorgan.py
python Q4_lambda_cut.py
python Q5_perceptron.py
```

No external packages required.

Files:
- `Q1_fuzzy_operations.py`: union, intersection, complement, algebraic sum/product, Cartesian product.
- `Q2_fuzzy_composition.py`: max–min and max–product composition of fuzzy relations.
- `Q3_demorgan.py`: verifies De Morgan’s laws for fuzzy sets.
- `Q4_lambda_cut.py`: λ-cut and strong λ-cut.
- `Q5_perceptron.py`: perceptron learning rule demo on AND gate.
