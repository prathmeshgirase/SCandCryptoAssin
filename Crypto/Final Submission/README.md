## Crypto Assignment Solutions (Python)

Run any script with Python 3:

```bash
python unit1_substitution.py
python unit2_transposition.py
python unit3_diffie_hellman.py
python unit4_rsa_password.py
python unit5_hash_base64_and_simplecrypt.py
```

Dependencies for Unit IV and optional part of Unit V:

```bash
pip install pycryptodome simple-crypt
```

Files:
- `unit1_substitution.py`: Caesar, Modified Caesar (Vigenère), Playfair
- `unit2_transposition.py`: Rail Fence, Columnar Transposition
- `unit3_diffie_hellman.py`: Diffie–Hellman demo with small parameters
- `unit4_rsa_password.py`: RSA (OAEP) password encrypt/decrypt example
- `unit5_hash_base64_and_simplecrypt.py`: MD5, SHA-256, base64 encode/decode, optional simple-crypt
